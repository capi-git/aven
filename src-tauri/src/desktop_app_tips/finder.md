# Finder
- Prefer your own file tools for reading, moving or renaming files. Use Finder only when the user wants to see or check Finder itself.
- Files appear as rows (list view), cells (column view) or images (icon view). Clicking selects an item; opening needs a double-click, which Aven sends as app-directed mouse events.
- The sidebar lists locations as rows. The search field is in the toolbar.
- Never delete, move to Trash or empty Trash without the user's explicit confirmation.
