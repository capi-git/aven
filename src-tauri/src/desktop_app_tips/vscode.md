# Visual Studio Code
- VS Code is an Electron app; Aven turns on its accessibility tree on first use. Call appState again if the editor area looks empty.
- The editor text is a large text area. Prefer editing files with your own file tools rather than typing into the editor through desktop control.
- Use the Command Palette only when needed: pressKey with cmd+shift+p requires that VS Code's window is focused and the user expects it.
- Tabs, the activity bar and side bar views are buttons and tree items. Click them by element index.
- Integrated terminal content is often not exposed as text; take a screenshot to read it.
