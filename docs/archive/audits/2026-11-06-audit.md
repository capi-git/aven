# Audit: security, speed, unused code and naming (6 November 2026)

Read-only review of `main` at `f49c8d8a`, followed by the fixes listed under **Done**. No high-severity security issue was found.

## Done in this change

- **External browser:** macOS opened links only in Brave, so the action failed for anyone without it. Links now open in the system default browser on every platform, and the opener permission no longer names an app.
- **Unused code:** removed `WorkspaceColorPicker`, 40 exports that nothing referenced, and `public/aven-background.png` (1.5 MB, shipped in every build, used nowhere).
- **Names:** comments, a test name and design notes no longer cite MonoCode commits; attribution stays in `NOTICE`, `README.md` and `docs/UPSTREAM.md`. Built-in skills are labelled `aven`; the old `monocode` label is still read.
- **Release tools:** `dtolnay/rust-toolchain` and `Swatinem/rust-cache` are pinned to commit SHAs (with `toolchain: stable` stated, since a SHA cannot name it).
- **Mock-ups:** `sanitizeMockupHtml` cleans its own output again until it stops changing, so markup that turns harmful only when re-read is caught.
- **Skills installer:** pinned to `skills@1.7.6`, the version everyone already ran.
- **System tools:** the macOS calls to `security` and `open` use `/usr/bin/...` rather than `PATH`.
- **Unused commands:** removed `git_pull`, `read_file_preview` (which could read any file) and `notes_get`.
- **Docs:** dated audits, research and design mocks moved to `docs/archive/`; added `docs/README.md` as a starting map.

## Open: security

1. **Medium.** The release job imports and unlocks the Developer ID keychain before `npm ci`, tests and `tauri build` (`.github/workflows/release.yml`, `scripts/ci-signing-keychain.py`). Any dependency install script or `build.rs` could sign binaries with Aven's identity. Import the keychain just before signing instead.
2. **Low.** Consider no Rust cache at all in release jobs, so a poisoned cache cannot reach a signed build.
3. **Low.** Agents' `AVEN_CONTROL_TOKEN` / `AVEN_BROWSER_TOKEN` are inherited by every script an agent runs, which can then drive the logged-in browser profile.
4. **Low.** `src/lib/crewMockups.ts` still sanitises mock-up HTML by hand (now re-checked to a fixed point); DOMPurify would be sturdier but is not a direct dependency.
5. **Low.** No Tauri app manifest, so every webview window can call every command; panel windows' capability files do not restrict commands.
6. **Check.** `desktop_control_macos.rs` extends a closure's lifetime with `transmute`; an abandoned call drops it after the caller's frame is gone. Needs a `SAFETY` note and review. `Entitlements.plist` grants `allow-unsigned-executable-memory`; confirm Chromium still needs it.

## Tried and reverted: CodeMirror out of startup

Bot fix cards, crew cards and a team's batch import the diff viewer directly, which puts the CodeMirror group (435 KB minified) in startup. Loading it lazily cut startup JavaScript from 3,794,836 to 3,321,680 bytes, but the speed test (`npm run perf:app`, alternating builds on one Mac) showed no measurable launch gain and a slower first chat: "open six chats with replies" took about 80 ms on `main` in two runs and 97–126 ms in four lazy runs, whether the viewer was preloaded at idle or loaded per screen. Chats show diffs and editors soon after launch, so the cost only moved. Keep CodeMirror in startup unless chats stop needing it early.

## Open: speed

1. `src/lib/fileIndex.ts` rescans the project file list on every window focus while anything is subscribed. Left as is on purpose: throttling it would delay files added outside Aven. Measure before changing.
2. The composer's agent mark runs endless resting and watching animations (`src/chrome/AgentMark.css`), against the rule in `docs/PERFORMANCE.md` that an idle window draws no motion. Needs a design decision.
3. Smaller: `native_popup.rs` starts a sleeping thread per popup hide; `TerminalGridBackground` requests every frame but draws every 33 ms; `AgentTranscript` adds and removes a wheel listener per live tool phase.

## Open: needs a person to decide

- `takeInFlightSessions` and the `session_take_in_flight` command are never called, so the in-flight sessions Aven records are never read back. Crash recovery of running chats may have been dropped rather than finished.
- About 127 exports are used only by tests; some (tab group editing, workspace colour presets, editor Git helpers) look like features that were built but never wired up.
- `public/aven-mark.png` is a byte-identical copy of `public/aven.png`; 35 iOS and Android icons (597 KB) are kept for a desktop-only app.

## Names that still say MonoCode or SuperMono

These are deliberate; see `docs/BRANDING.md`. The production bundle ID `com.capi.monocode.personal` holds every user's chats and settings, about 100 saved settings keys start with `monocode.`, and the Chromium bridge uses `supermono_*` names. Renaming them needs a tested data migration, not a find-and-replace.
